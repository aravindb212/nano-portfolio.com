# Aravind AI Research Portfolio

Advanced static portfolio website for Aravind B.

## Included

- Animated neural-network background
- Responsive dark/light theme
- Research dashboard
- Healthcare AI solutions
- Project metrics
- Experience timeline
- Awards and certifications
- Publications
- Technology filter dashboard
- Portfolio chatbot using local knowledge
- Local profile view counter
- Contact button using `aravi.nano@gmail.com`

## Deployment

Upload the contents of this folder to the root of:

`https://github.com/aravindb212/nano-portfolio.com`

Ensure these files are in the repository root:

- `index.html`
- `style.css`
- `script.js`

Then enable GitHub Pages from the `main` branch and `/ (root)`.

## Important notes

The chatbot is currently a frontend demonstration. For a real AI chatbot, add a secure serverless backend and keep API keys off the client.

The current profile counter uses browser local storage, so it is not a global visitor counter. Replace it with an analytics/database service for real cross-user statistics.

Replace placeholder publication links with verified URLs when available.
